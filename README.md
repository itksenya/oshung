# oshung

## Google Analytics

App sends GA4 page views to `G-8NXRSMKKRS`. To use another web data stream, set
`GA_MEASUREMENT_ID` before starting Streamlit:

```bash
GA_MEASUREMENT_ID=G-XXXXXXXXXX streamlit run Colortype.py
```

Photo analysis identifies facial zones and the color of three key points: eyes, hair, and skin. Enter your gender, height, and measurements to receive results: color type, Kibbe body type, and figure type. Recommendations for clothing, hairstyle, and makeup are provided, along with examples of models and celebrities matching your profile.
